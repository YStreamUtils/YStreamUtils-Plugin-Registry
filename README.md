## The Stream Companion Plugin Repository You Didn't Ask For

This is where my "official" plugin repository is.

It has a [master registry](https://ystreamutils.github.io/YStreamUtils-Plugin-Registry/registry.json) that the application expects.

## Generally speaking

Plugin updates happen automatically on the hour, should be automatically merged.

## Plugin Development

[Check the OBS plugin repo](https://github.com/YStreamUtils/OBS-Plugin)

I am NOT opening the registry for others, please see this repo for information on how to make your own.

Plugins can be sideloaded as long as the manifest attribute is present, all the registry does is spit out a json file.
